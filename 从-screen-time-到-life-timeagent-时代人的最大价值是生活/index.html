从 Screen Time 到 Life Time：Agent 时代，人的最大价值是生活

前段时间看到千问Qwen3.8发布的视频，里面有一个很打动人的表达：AI 开始替人干活以后，人终于可以从电脑和手机前离开，重新回到生活。

这个画面几乎代表了这一轮 AI 最令人期待的未来。过去我们每天坐在电脑前处理邮件、整理文档、搜索资料、做 PPT、填表格，在不同 App 之间复制粘贴；以后这些事情交给 Agent，人只需要告诉它自己想要什么，然后去陪家人、运动、旅行、晒太阳，或者干脆什么都不做。

但现实正在出现一个很有意思的反差。

AI 已经开始替我们干活了，越来越多人也确实感受到效率提升，可人似乎并没有因此闲下来。很多人的感受甚至恰恰相反：AI 用得越多，工作反而越多了。

于是，一个比“AI 能不能提高效率”更值得讨论的问题出现了：

AI 明明在帮我们节省时间，为什么我们反而更忙了？

这个问题可能比“AI 会不会取代工作”更重要。因为它决定了 AI 最终带给我们的，究竟只是一次更大的生产力革命，还是一次人与数字世界关系的真正改变。

一、过去 50 年，我们一直在走进计算机
#

回头看过去几十年的个人计算史，会发现一条非常清晰的路径。

PC 出现以后，人开始坐到计算机面前工作；互联网出现以后，我们进入浏览器；智能手机出现以后，计算机进入口袋；移动互联网再往前一步，让人几乎随时随地处于在线状态。

PC → Internet → Smartphone → Mobile Internet → Always Online。

计算机越来越小，网络越来越快，软件越来越容易使用。表面上看，技术一直在努力适应人，但与此同时，另一个方向也在悄悄发生：人也越来越适应计算机。

工作、购物、支付、社交、娱乐、学习、导航、旅行，越来越多原本发生在真实世界里的事情，被搬进了屏幕。今天已经很难严格区分“上网”和“不上网”，因为数字世界已经变成生活本身的一部分。

问题在于，数字世界虽然越来越方便，却仍然需要大量的人类操作。

每天早上打开电脑，我们做的很多事情其实非常机械：查看信息、判断优先级、搜索资料、打开网页、点击按钮、填写表格、复制粘贴、回复消息、转发文件、切换窗口、检查任务状态。

很多所谓的知识工作拆开以后，会发现人其实承担了大量 Computer Operator 的角色。

过去几十年的数字化，一边提高了效率，一边也把大量人类注意力变成了数字世界的“操作资源”。

我们造出了越来越强大的计算机，却也花了越来越多时间操作计算机。

二、Agent 真正改变的，是谁在操作计算机
#

ChatGPT 刚出现的时候，我们最关心的问题是：AI 能不能回答我的问题？

到了 Agent 阶段，问题开始变成：AI 能不能替我把事情做完？

这个变化看起来没有那么惊天动地，但它可能比模型能力继续提高几个百分点重要得多。

传统的软件世界里，一件事情通常是这样的：

Human → GUI → App → Action

人理解自己的目标，然后把目标拆解成一系列计算机能够理解的操作：打开哪个 App、点击哪个按钮、输入什么内容、复制什么信息、下一步去哪里。

Agent 出现以后，这条链路开始变成：

Human → Intent → Agent → Apps / Web / API → Action

人不再需要把意图翻译成几十次点击，只需要表达自己的目标，剩下的事情由 Agent 在数字世界中完成。

比如以前准备一次旅行，你可能需要自己搜索机票、比较酒店、查看地图、确认天气、填写订单、完成支付，再把行程加入日历。未来可能只需要说一句：“下周去上海三天，还是按照我平时的习惯安排。”

真正发生变化的，并不是订机票快了几分钟，而是谁在操作计算机发生了变化。

以前，人是 Operator；未来，Agent 是 Operator，人逐渐变成 Principal、Decision Maker。

所以 Agent 最重要的变化，也许不是计算机终于变得足够聪明，而是：

计算机终于开始自己操作计算机。

这也是为什么 Agent 第一次有机会真正减少人的 Screen Time。过去的软件一直在研究怎样让人更高效地使用计算机，而 Agent 开始让我们思考另一个问题：怎样让人不再需要使用那么多计算机？

三、AI 越高效，我们为什么反而越忙？
#

这里出现了一个生产力悖论。

我们通常会把技术进步理解成这样一条路径：

效率提高 → 更快完成工作 → 获得更多自由时间。

但现实中的路径经常是另一种样子：

效率提高 → 单位时间产出提高 → 工作预期提高 → 更多任务 → 更高产出。

假设过去一个人一天只能写 3 份报告，AI 出现以后，一天可以写 10 份。最理想的结果当然是下午三点完成工作，然后下班。但更可能发生的是：以后每天的目标变成 10 份报告。

AI 节省出来的时间，并没有真正变成个人可以自由支配的时间，而是被重新吸收进生产系统，变成了更多的产出。

于是 AI 的路径变成：

AI → Productivity ↑ → Output ↑ → More Work

而不是：

AI → Productivity ↑ → Time Saved → More Life

这可能就是为什么 AI 一边让人感觉“很多事情变快了”，另一边却没有让人明显感觉“生活变轻松了”。

技术能够创造时间，却不能决定这些时间最终属于谁。

工业时代的机器如此，信息时代的软件如此，AI 也不会天然例外。只要衡量人的方式仍然是“你能完成多少工作”，那么生产力提高以后，最容易发生的事情就是工作量跟着生产力一起提高。

所以“AI 替人工作”与“人因此获得更多生活”，其实是两件完全不同的事情。

前者是一个技术问题，后者则是一个关于组织、产品甚至社会如何分配 AI 生产力红利的问题。

四、就算工作把时间还给你，互联网也在等着拿走它
#

事情还没有结束。

假设 Agent 真的帮我们省下了两个小时，而且公司也没有马上用更多工作填满它，这两个小时就真的属于我们了吗？

未必。

过去二十年的互联网已经建立了一套极其成熟的注意力机器。

Feed、Push、短视频、社交网络、推荐算法，每一种产品机制都在解决同一个问题：怎样让用户打开得更多、停留得更久、互动得更多。

这正是上一篇文章讨论的流量飞轮：

Attention → Engagement → Traffic → Monetization。

于是过去几十年出现了一个很有意思的循环：技术不断帮助我们节省时间，互联网又不断找到新的方法，把这些时间重新变成流量。

搜索引擎让寻找信息更快，即时通信让沟通更快，智能手机让很多事情随时可以完成。按理说，我们应该越来越有空，但结果却是 Screen Time 越来越长。

效率提高，并不会自动带来自由。

因为节省下来的注意力本身就是一种极其有价值的资源。工作想要它，互联网也想要它。

所以 AI 想真正把人从数字世界里释放出来，至少需要面对两个“吞噬机制”：生产系统会把效率红利重新变成更多工作，注意力经济会把空闲时间重新变成更多流量。

这也是为什么“AI 替我们干活，人就会回到生活”听起来如此美好，实现起来却远没有那么简单。

五、Attention Saved 还不够，我们需要 Attention Returned
#

上一篇文章里，我把 Agent 时代一个非常重要的产品指标定义为 Attention Saved。

一个好的 Agent，不应该用“用户每天打开我多少次”证明自己的价值，而应该看它替用户处理了多少事情、减少了多少人工介入、节省了多少注意力。

但继续往前推一步，会发现 Attention Saved 其实还不是终点。

因为还有一个问题：

Saved for what？

假设 Personal Agent 每天替你节省两个小时。一个小时被公司变成更多任务，另一个小时被短视频填满。AI 的确提高了效率，但从人的角度看，生活并没有发生根本变化。

所以在 Attention Saved 之后，还需要另一个概念：

Attention Returned。

过去互联网做的是：

Attention Captured。

Agent 首先应该做到：

Attention Saved。

但真正值得期待的 Personal Agent，最终应该做到：

Attention Returned。

Attention Saved 是 Agent 替你节省了多少注意力；Attention Returned 则更进一步——Agent 从数字世界里替你拿回注意力，并把这部分注意力的支配权真正还给你。

两者看起来很像，其实区别很大。

Saved 是效率指标，Returned 是人的指标。

这也决定了我们究竟应该怎样设计下一代 Personal Agent。

六、Agent 不应该成为新的 Attention Machine
#

这里其实存在另一个值得警惕的方向。

今天的互联网产品靠通知、Feed 和推荐争夺注意力。未来的 Agent 如果继续沿用这套产品逻辑，很容易变成一个更加聪明的注意力机器。

它可能不断主动告诉你：

“我发现了一件你可能感兴趣的事情。”

“这里有三个新的建议。”

“你还有五个任务没有完成。”

“根据你的兴趣，我又整理了一些内容。”

过去是 App 给我们发通知，未来可能变成 Agent 主动找我们聊天。技术变了，争夺注意力的逻辑却一点没变。

这样的 Agent 即使拥有更强的模型、更长的记忆和更高的自主性，也只是制造了一个更加聪明的 Feed。

真正成熟的 Personal Agent 应该走向完全不同的方向。

它应该站在人和数字世界之间：

Digital World → Personal Agent → Human

邮件、消息、会议、通知、任务、各种 App、Web 服务甚至其他 Agent，大量事情应该停留在 Personal Agent 这一层。Agent 自己理解、过滤、处理、执行，只有真正需要人的判断、决策、情感、创造力或者责任承担时，才把事情交还给人。

从这个角度看，Personal Agent 一个非常重要却容易被忽略的能力，也许是 Interruption Management。

好的 Agent 不是更频繁地提醒你世界发生了什么，而是让绝大多数事情根本不需要打扰你。

过去的软件竞争谁能占据更多注意力，未来的 Agent 也许应该竞争：

谁能更少地打扰用户。

这其实是一种完全不同的产品哲学。

七、当 Agent 成为 Operator，人应该重新做什么？
#

如果 Agent 真的开始承担数字世界里的大量操作，一个更大的问题就出现了：

人应该做什么？

答案当然不是“什么都不做”。

恰恰相反，我们需要重新区分什么事情更适合机器，什么事情真正值得人投入注意力。

机器越来越擅长的是信息搜索、信息过滤、重复执行、流程协调、状态跟踪、规则判断、跨系统操作，以及大量可以被明确描述和验证的数字劳动。

而人的注意力真正稀缺的地方，可能一直是另外一些东西：体验、关系、判断、创造、好奇、身体、情感，以及真实世界。

陪孩子玩一个下午，和朋友认真吃一顿饭，在陌生城市里漫无目的地走一走，读一本没有任何“产出”的书，花几个小时思考一个暂时没有答案的问题，甚至只是坐在那里发呆。

这些事情很难被计算成 Productivity，却构成了生活本身。

所以 Agent 的意义，不应该只是让人有更多时间继续做机器擅长的事情，而应该让人重新把时间花在人真正擅长、也真正需要亲自经历的事情上。

这里甚至可以反过来看今天大量的知识工作：每天读取信息、分类、总结、回复、转发、填表、搬运数据、切换窗口、检查状态。

AI 最值得替代的，也许不是人的工作，而是那些让人活得越来越像机器的工作。

八、从 Screen Time 到 Life Time
#

过去几十年的数字产品有一个非常有代表性的指标：Screen Time。

虽然它并不总是一个产品 KPI，但它非常准确地描述了互联网时代人与计算机之间的关系——越来越多的生活，通过屏幕完成。

Personal Agent 有机会第一次让这个方向发生逆转。

因为当 Agent 可以替人理解信息、操作软件、访问 Web、调用 API、协调其他 Agent，人就不再需要亲自进入数字世界完成每一个步骤。

这时候，衡量 Personal Agent 的价值，也许应该出现一个与 Screen Time 相反的概念：

Life Time。

Life Time 并不是简单地统计“每天少看了多少分钟手机”，而是在问一个更重要的问题：

有多少原本必须由人亲自进入数字世界完成的事情，现在可以放心地留给 Agent？

于是前三篇文章里的很多概念，在这里终于可以连接成一条完整的链：

Trust ↑ → Delegation ↑ → Autonomy ↑ → Human Intervention ↓ → Attention Saved ↑ → Attention Returned ↑ → Life Time ↑

第一步是 Trust。

只有信任 Agent，我们才愿意 Delegation；只有更多 Delegation，Agent 才能够获得真正的 Autonomy；自主性提高以后，人对数字世界的直接介入开始减少，于是产生 Attention Saved。

但这条链真正有意义的终点，不应该停留在效率。

它应该继续走向：

Attention Returned。

然后才是：

Life Time。

九、AI 替我们工作之后，省下来的时间到底属于谁？
#

现在再回头看“AI 替人干活，人回到生活”这句话，会发现真正困难的其实是后半句。

让 AI 干活，主要依赖技术进步。

让人回到生活，却需要我们重新思考工作的组织方式、产品的商业模式、Agent 的设计目标，以及我们究竟怎样理解技术进步。

如果 AI 每提高 10% 的生产效率，我们就增加 10% 的工作；如果 Agent 每替我们节省一个小时，就立刻有另一个产品来占据这个小时，那么 AI 最终只是让整个社会运行得更快，而不一定让人的生活变得更好。

这也是为什么 Agent 时代真正值得讨论的，不应该只有 Capability。

我们还需要讨论另一个问题：

AI 创造出来的 Attention Dividend，最终属于谁？

属于公司，意味着更多 Output。

属于互联网平台，意味着更多 Engagement。

真正属于个人，它才可能变成 Life Time。

这或许才是“AI 解放人”真正需要跨过去的那道门槛。

十、人应该重新回到生活
#

过去几十年的数字化，把人越来越深地拉进计算机。

我们从偶尔使用 PC，到随身携带 Smartphone，再到今天的 Always Online。计算机越来越懂我们，我们也越来越习惯把自己的时间、注意力和生活交给屏幕。

Agent 第一次给了这条路径一个反向运动的可能。

过去是：

Human → Computer → Internet → Always Online

未来有可能变成：

Digital World → Personal Agent → Human

不是人不断进入数字世界寻找信息、处理任务、操作软件，而是 Agent 留在数字世界里替我们工作，只把真正需要人的事情带回来。

这可能才是 Personal Agent 最值得期待的地方。

它不只是一个更聪明的 Chatbot，也不只是一个更高效的生产力工具。它可能成为人与数字世界之间的一层缓冲，把那些机器更擅长的事情留给机器，把人的注意力重新还给人。

所以 AI 最终带来的变化，也许不应该只是“一个人一天可以完成过去十个人的工作”。

更值得期待的未来是：当越来越多数字劳动被机器接走以后，我们终于不再需要把自己训练成一个高效的计算机操作员。

过去的软件一直在想办法让我们更高效地使用计算机。Agent 真正值得期待的地方，是有一天，我们终于可以少用一点计算机。

而省下来的那些时间，不再变成新的 KPI，不再变成新的 Feed，不再被下一个数字产品重新拿走。

它可以重新属于家人、朋友、身体、兴趣、创造、思考、真实世界，也可以什么都不属于。

只是属于你自己。

AI 最终的意义，也许不是让机器越来越像人，而是让人不必再活得越来越像机器。
