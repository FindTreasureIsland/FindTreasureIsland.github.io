引子
#

2026年9月8日，Meta 正式发布了个人AI Agent 产品，Muse。

2026年9月9日，苹果发布了它的首款折叠屏手机 Duo，市场一片好评。

这两个看起来貌似没有太大关系的产品，却让我开始重新思考一个已经存在了四十多年的东西：个人计算机。

前者代表的是一种越来越清晰的 Agent 形态：Agent 不只是和你聊天，而是拥有一台运行在云端的计算机。它可以使用浏览器、操作文件、运行程序，甚至像一个真正的人一样使用各种软件。后者看起来则只是一台屏幕更大的手机。

但如果把这两件事情放在一起看，一个非常有意思的问题就出现了：我们以后真的还需要一台个人电脑吗？

过去二十年，这个问题其实已经被问过很多次。智能手机出现的时候问过，iPad 出现的时候问过，折叠屏出现的时候问过，手机厂商推出 PC Mode 的时候也问过。但每一次，PC 最后都活了下来。

所以这一次有什么不同？

我认为真正的变化既不是手机性能更强了，也不是折叠屏终于足够大了，而是一个过去从来没有发生过的变化正在出现：人可能不再是计算机的主要操作者了。

如果这个变化真的发生，那么 Muse 和 Duo 所代表的就不仅仅是两个新的产品，而可能是一次关于“Personal Computer”本身的重新定义。

从大型机到 PC，再到云计算
#

回头看计算机的发展历史，会发现计算能力其实一直在“集中”和“分散”之间摆动。

最早的大型机时代，计算能力高度集中。一台昂贵的大型计算机服务很多人，普通用户只是通过终端连接它。后来个人计算机出现，计算能力第一次真正从中心下放到了个人。每个人都可以拥有自己的 CPU、内存、硬盘和操作系统。

这件事情的意义非常深远，因为从那以后，我们不再只是“使用计算资源”，而是开始“拥有一台计算机”。PC 也因此成为过去几十年信息产业最重要的基础设施之一。

互联网出现以后，服务器越来越多，然后又出现了云计算。AWS、Azure 这些云计算平台，本质上做了一件非常重要的事情：把服务器重新集中起来。

过去企业需要自己购买服务器、建设机房、安装操作系统、维护硬件。云计算出现以后，服务器逐渐变成了一种可以随时购买、随时释放的计算资源。需要 2 核就用 2 核，需要 64 核就用 64 核，需要 GPU 就临时增加 GPU。

所以从这个角度来看，过去二十年的云计算，本质上完成的是一次 Server 的云化。

但是有一个东西一直没有真正完成云化，那就是 Personal Computer。

这件事情其实很奇怪。因为今天绝大多数个人电脑在绝大多数时间里，计算能力都是闲置的。我们为了偶尔剪一次视频购买更强的 CPU，为了偶尔运行一些 AI 程序购买 GPU，为了偶尔处理大型文件购买 32GB、64GB 内存。但一天 24 小时里面，这些硬件绝大部分时间并没有真正发挥能力。

服务器早已经从“购买机器”变成了“购买计算能力”，为什么个人计算机仍然停留在几十年前的模式——每个人购买一套固定配置的 CPU、GPU、内存和存储，然后把它放在自己的桌子上？

原因可能并不是技术做不到，而是过去始终存在另外一个问题：人必须操作它。

为什么智能手机始终没有杀死 PC？
#

过去几十年，试图挑战 PC 的产品其实非常多。

瘦终端试过，VDI 试过，Cloud PC 试过；智能手机出现以后，手机 PC Mode 试过；iPad 和各种平板电脑试过；后来折叠屏又试了一次。英伟达等公司甚至通过云游戏证明，高性能 GPU 本身也不一定非要放在用户身边。

但这些产品最后都没有真正取代 PC。

一个很容易想到的解释是性能，但我认为这并不是最重要的原因。今天一台旗舰手机的性能其实已经非常强大，真正的问题在于：复杂工作需要复杂操作。

写程序需要 IDE、Terminal，需要同时查看代码、文档和运行结果；做 PPT 需要不断拖拽、调整和排版；Excel 需要面对复杂的表格、公式、数据和图表；设计、视频剪辑、文件管理同样需要大量连续操作。

这些工作的共同特点，是人在很长一段时间里需要持续操作计算机。

所以我们需要大屏幕，需要键盘鼠标，需要窗口，需要文件系统，需要复杂的软件界面。PC 最重要的价值其实不只是计算能力，而是它提供了一个非常适合人类进行复杂数字工作的操作台。

过去所有挑战 PC 的产品，都没有改变这个基本事实。

瘦终端只是把计算搬到了服务器，Cloud PC 只是把 Windows 搬到了云端，云游戏只是把 GPU 搬到了数据中心，手机 PC Mode 则试图让手机变成一台电脑。它们改变了计算发生在哪里，却始终没有改变一个最重要的问题：

操作计算机的人，还是你。

你还是要移动鼠标、打开软件、管理窗口、处理文件，还是需要学习 Photoshop、Excel、Premiere 和各种 IDE。

这也是为什么 Cloud PC 长期面临一个非常现实的问题——延迟。鼠标移动以后晚 100 毫秒才有反应，人会觉得难受；拖动窗口不流畅，人会觉得难受；画面卡顿，人也会觉得难受。因为人的操作是实时的。

所以过去几十年，我们其实早就拥有了把“计算”搬到云端的技术，却始终很难把“个人计算机”真正搬到云端。

直到 Agent 出现。

Agent 真正改变的，是“谁在操作计算机”
#

我认为这是这一轮 AI 革命中一个非常容易被低估的变化。

过去我们使用 ChatGPT，本质上仍然是在和 AI 对话。AI 告诉你怎么做，然后你去做。但 Agent 开始不一样了，它不只是告诉你应该怎么做，而是开始替你做。

它可以自己打开浏览器，搜索资料，下载文件，写代码，运行程序，整理数据，制作文档，甚至操作一整套软件。

于是一个存在了几十年的关系开始改变。过去是 Human → Computer，人操作计算机；未来可能变成 Human → Agent → Computer，Agent 操作计算机。

看起来只是中间多了一层，但这一层可能会动摇 PC 存在几十年的根基。

比如我要做一份新能源汽车行业研究报告。过去我要坐在电脑前，打开浏览器、搜索资料、下载 PDF、建立文件夹、整理数据，再打开 Excel 做分析，最后打开 PowerPoint 写内容、找图片、排版、修改、导出。

整个过程中，真正消耗我大量时间的其实不是“思考新能源汽车行业”，而是操作计算机完成这些事情。

Agent 时代则可能完全不同。

我只需要告诉它：“研究过去五年中国新能源汽车行业的发展情况，重点分析市场规模、竞争格局和未来三年的趋势，然后做一份 20 页 PPT。”

20 分钟以后，Agent 通知我第一版已经完成。我拿出手机看一下，发现第三部分的数据不太准确，于是告诉它：“第三部分重新查一下，优先使用官方数据。”

然后我把手机放回口袋。

30 分钟以后它再次通知我。我重新检查，确认结果，然后批准。

在这个过程中，我真正做的事情只有几个：提出目标、检查结果、进行判断、提出修改和最终批准。

人的角色已经从 Operator——计算机操作者，逐渐变成了 Supervisor——Agent 的监督者。

这才是 Agent 对 PC 真正危险的地方。

为什么偏偏是现在？
#

如果云端计算机这么合理，为什么十年前没有发生？如果手机真的能够成为个人计算终端，为什么 iPhone 出现近二十年以后 PC 仍然存在？

因为过去始终缺少几块关键拼图，而它们直到最近才开始同时出现。

第一块拼图是大模型终于提供了一种足够通用的人机接口。

过去想让计算机完成一个复杂任务，我们必须学习计算机的语言。学习菜单在哪里，按钮在哪里，软件怎么使用，文件怎么组织，命令怎么输入。GUI 已经比命令行简单很多，但本质上仍然是人适应机器。

大模型第一次让这个关系有可能反过来。人可以直接描述目标：“帮我完成这件事情。”至于后面需要打开几个网页、调用几个 API、写多少代码、操作什么软件，可以由 Agent 自己决定。

第二块拼图，是 Agent 开始真正拥有 Computer Use 能力。

只有聊天能力远远不够。真正能够改变 PC 的 AI，必须能够使用浏览器、操作文件、执行代码、调用软件、管理任务，并且能够持续工作几十分钟甚至几个小时。

换句话说，AI 必须从 Chatbot 变成 Worker。

第三块拼图，是云计算基础设施已经足够成熟和便宜。

二十年前如果给每个人长期准备一台云端计算机，成本可能完全不可接受。但今天虚拟机、容器、Serverless、GPU 云服务已经高度成熟。计算资源可以动态创建、按需扩容、完成以后立即释放。

这意味着未来一个人甚至不需要“一台”固定的云电脑。Research Agent 工作的时候临时创建一套环境，Coding Agent 再创建另外一套，视频 Agent 临时调用 GPU。任务结束以后全部释放。

第四块拼图，是移动终端已经足够成熟。

智能手机拥有全天候网络、足够好的屏幕、摄像头、麦克风、生物识别和通知系统。Duo 这样的折叠大屏设备进一步解决了一个问题：手机足够便携，但展开以后又足够适合检查复杂内容。

于是这几件事情第一次同时发生：

AI 可以理解人的目标，Agent 可以操作计算机，云端可以低成本提供计算资源，而人手里已经有了一台全天在线、随身携带的大屏终端。

过去缺任何一块，这个模式都很难成立。

现在，它们第一次开始拼到了一起。

Muse 可能代表的，是 Personal Computer 的云化
#

如果从这个角度来看 Muse，就会发现它真正值得关注的并不只是“又一个 AI Agent”。

真正重要的是，Agent 开始拥有自己的 Computer。

过去我们默认一个基本关系：人拥有一台电脑，然后人在电脑里面运行软件。但 Muse 这种模式开始变成：Agent 拥有一个运行在云端的计算环境，然后 Agent 在里面完成工作。

浏览器在那里，文件在那里，程序在那里运行，工作环境也在那里。

过去二十年 AWS 完成的是 Server → Cloud Server，而 Agent 时代可能正在开始另外一场迁移：

PC → Cloud Personal Computer。

Manus 的肖弘曾经说过一句很值得琢磨的话：“越来越觉得卖 Manus，越来越像卖计算机。”

这句话如果放到今天来看，可能比它表面上的意思更加重要。

未来所谓的“个人计算机”，可能真的不再是一台放在桌子上的机器，而是一套属于你的、运行在云端、可以随时创建、扩展和销毁的计算环境。

Duo 真正的意义，可能不是让手机变成电脑
#

如果只有云端 Agent Computer，其实还不够，因为人仍然需要一个终端。

我们需要查看 Agent 在做什么，需要阅读报告、检查 PPT、查看图片、确认代码运行结果，需要授权，需要纠偏。

这个时候，Duo 这样的设备就变得非常有意思。

过去折叠屏一直在试图回答一个问题：怎么让手机越来越像电脑？

所以大家强调大屏、多任务、分屏、键盘和桌面模式。但 Agent 出现以后，我觉得这个问题可能应该反过来：

为什么手机一定要变成电脑？

如果真正复杂的工作已经交给 Agent，我们根本没有必要在一个七八英寸的屏幕上操作完整的 Photoshop，也没有必要在手机上操作复杂的 Excel，更没有必要打开一个拥有几十个窗口的 IDE。

这些事情应该交给 Agent。

人真正需要的是检查。

看看报告是否正确，看看 PPT 是否合适，看看 Agent 修改后的图片，看看程序运行结果，然后告诉它：“可以”“这里不对”“重新做”“继续”“执行”。

过去 PC 是一个 Creation Device，因为人必须亲自完成大量生产过程。

Agent 时代，人需要的设备可能越来越接近一个 Supervision Device。

而折叠屏恰恰非常适合这种需求：合起来足够便携，展开以后足够检查复杂内容，始终联网，并且随时可以介入 Agent 的工作。

所以 Duo 真正值得想象的定位，可能不是“一台可以变成电脑的手机”，而是：

Personal Agent Terminal——个人 Agent 终端。

PC 时代要求人连续工作，Agent 时代可能把工作变成“随机检查”
#

这里还会带来另外一个非常有意思的变化：我们的工作方式本身可能发生改变。

PC 时代的工作通常具有很强的连续性。你来到办公室，坐到电脑前，打开各种软件，然后连续工作两三个小时。因为你就是任务的执行者，一旦离开电脑，工作往往也就停止了。

Agent 完全不同。

你早上在地铁上给 Agent 分配一个任务。Agent 工作 40 分钟，然后通知你检查。你在电梯里花两分钟看一下，说：“第二部分重新做。”它继续工作。中午吃饭的时候再次通知你，你展开 Duo 看五分钟，批准其中三个任务，修改另外两个任务。

Agent 一直在连续工作，而人只需要随机介入。

这意味着工作可能从过去的“连续操作”，变成一种 异步监督。

过去我们必须“坐在电脑前工作”，未来可能变成“Agent 一直在工作，人随时进行检查”。

如果这种工作方式真的普及，那么移动设备相对于 PC 的价值会进一步提高。因为监督并不要求你一直坐在一个固定的位置，它要求的是：Agent 需要你的时候，你可以随时出现。

这可能是 Duo 和 Agent 组合以后真正具有颠覆性的地方。

下一代 Personal Computing 的结构可能已经隐约出现
#

如果把 Muse 和 Duo 放在一起，一个新的个人计算架构其实已经隐约出现：

Human → Duo / Phone / Glasses → Personal Agent → Cloud Computer → Browser / Files / Apps / API / Other Agents。

手机负责人与 AI 的交互，Agent 负责理解目标和执行任务，Cloud Computer 负责真正的计算，而人在这个体系中的主要职责变成目标、判断、检查和授权。

这和今天的计算机体系完全不同。

今天是 Human → Windows/macOS → Application。我们需要学习 Windows，学习 macOS，学习 Excel，学习 Photoshop，学习各种软件。

但未来可能变成 Human → Agent → Application。

甚至再往后，Application 这一层对普通用户都可能逐渐不可见。

你不会说“打开 Excel”，而会说“分析一下这些销售数据”；不会说“打开 Photoshop”，而会说“把这 50 张照片处理成统一风格”；不会说“打开 PowerPoint”，而只是说“帮我做一份融资路演”。

用户真正购买的不再是软件，而是能力。

于是 Application 也可能逐渐从 App 变成 Tool——从给人操作的产品，变成 Agent 可以调用的能力。

如果这件事情真的发生，被改变的就绝不仅仅是 PC
#

首先被改变的是个人电脑硬件。

今天我们讨论 Intel 还是 AMD，M5 还是 M6，16GB 还是 32GB，RTX 还是集成显卡。未来普通用户可能越来越不关心这些事情。

因为计算开始从 Buy Compute 变成 Consume Compute。

需要两核就调用两核，需要 64GB 内存就临时使用 64GB，需要 GPU 生成视频就调用 GPU。任务完成以后资源释放。

接下来受到影响的是操作系统。

今天 Windows 和 macOS 最重要的价值之一，是建立人与计算机之间的交互界面。窗口、菜单、Dock、任务栏、文件管理器、鼠标、快捷键，这些东西全部建立在一个基本假设之上：人是计算机的操作者。

如果未来计算机的主要操作者开始变成 Agent，那么操作系统最重要的用户甚至可能不再是 Human。

OS 的角色可能从 Human Interface 逐渐变成 Agent Runtime。

然后是软件行业。

过去几十年软件公司一直在研究一件事情：怎样设计一个更好的 UI，让人更容易使用软件。

未来软件公司可能需要面对完全不同的问题：怎样让 Agent 更容易调用我的能力？

GUI 的重要性可能下降，而 API、权限、结构化数据、Agent Interface 的重要性会越来越高。

所以如果这场变化真的发生，它影响的不会只是戴尔、惠普、联想或者 Mac，而是 CPU、GPU、操作系统、Office、Adobe、SaaS、云计算甚至整个软件产业。

Personal Computer 可能正在发生一次真正的词义变化
#

过去四十多年，Personal Computer 意味着“一台属于我的电脑”。

我的 CPU，我的内存，我的硬盘，我的操作系统，我的文件。

未来 Personal Computer 的定义可能变成：

属于我的计算环境。

至于这个环境究竟运行在哪里，可能并不重要。

甚至未来也不一定是 One Person → One Computer，而可能是 One Person → Many Agents → Many Computers。

Research Agent 有自己的 Computer，Coding Agent 有自己的 Computer，Marketing Agent 有自己的 Computer，Design Agent 有自己的 Computer。它们可以同时在云端工作。

于是未来甚至可能出现一个非常有意思的悖论：

传统 PC 的销量可能下降，但每个人实际使用的“Computer”数量反而可能暴增。

过去我们努力做到的是“一人一台电脑”，未来可能变成“一个人同时指挥几十台电脑”。

PC 不一定消失，但 PC 赖以存在的前提正在发生变化
#

当然，这并不意味着 PC 明天就会消失。

专业设计、游戏、工程、实时创作、极低延迟工作、本地隐私计算，以及很多需要高精度交互的场景，都会长期需要本地计算设备。

所以真正值得讨论的问题，并不是“Duo 会不会取代 MacBook”。

这个问题其实太小了。

真正的问题是：

当人不再是计算机的主要操作者，我们为什么还需要为人设计一台如此复杂的计算机？

过去几十年，我们一直在问：手机能不能取代 PC？平板能不能取代 PC？折叠屏能不能取代 PC？

这些问题可能从一开始就问错了。

因为它们都有一个共同的前提——人仍然需要亲自操作计算机。

Agent 第一次改变了这个前提。

这一次，不是另一种设备开始取代 PC，而是我们自己可能不再需要操作 PC。

过去四十年，我们一直在努力让每个人拥有一台更强大的电脑：更快的 CPU、更多的内存、更强的 GPU、更好的屏幕。

但 Muse 和 Duo 所代表的未来可能完全不同。

未来真正属于我们的，也许不再是一台电脑，而是一个 Personal Agent，以及它背后可以随时调用的无数计算资源。

手机是人的终端，Agent 是人的代理，云端是 Agent 的计算机。

而人真正需要做的，是那些至少在相当长时间内仍然很难完全交给机器的事情：提出目标、检查结果、做出判断和承担决策。

到了那个时候，我们也许会突然发现，PC 并不是被手机取代了，甚至也不是被 Agent 取代了。

真正发生的是：“个人计算机”正在从一台我们必须购买、携带和操作的物理机器，变成一种隐藏在 Agent 背后、随时可以调用的基础服务。

如果这一天真的到来，那么今天的 Muse 和苹果 Duo 看起来只是两个新产品。

但它们对世界的影响，可能比我们现在想到的都要大。
